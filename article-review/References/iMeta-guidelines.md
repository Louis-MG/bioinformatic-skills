## Journal Overview

### About iMeta

*iMeta* is a peer-reviewed, open access journal published by Wiley that focuses on microbiome research and related fields. The journal aims to advance understanding of microbial ecosystems and their interactions with hosts and environments.

### Journal Scope

The journal covers research in:
- Microbiome analysis
- Microbial ecology
- Metagenomics
- Bioinformatics
- Host-microbiome interactions
- Microbial community structure and function
- Multi-omics integration (iMetaomics)

## Original Article (Research Article) Requirements

### Article Type Specification

**Research Articles** are reports of new research findings or conceptual analyses that make a **significant contribution to knowledge** in the field of microbiome research.

### Word Count and Limits

| Element | Requirements |
|---------|--------------|
| **Main text** | 3,000 - 6,000 words |
| **Figures** | 4 - 6 figures |
| **Supplementary files** | No limit |
| **Abstract** | Required, Structured |
| **Keywords** | Maximum 7 |

### Required Sections

Manuscripts must include the following sections in this order:

1. **Introduction**
2. **Results**
3. **Discussion** (Results and Discussion may be combined)
4. **Conclusion**
5. **Methods**
6. **Acknowledgement**
7. **Author Contributions**
8. **Data and Code Availability**
9. **Competing Interests**
10. **References**

### Additional Requirements

- **Data and Code Availability Statement**: **Mandatory** for all Research Articles

## Submission Process

### Before You Submit - Checklist

**Required Elements:**

- [ ] Manuscript file (editable format with text, figures, tables OR separate files)
- [ ] All required sections included (Introduction, Methods, Results, Discussion, etc.)
- [ ] Abstract (structured)
- [ ] Figures with legends
- [ ] Tables with titles and footnotes
- [ ] References (any consistent style/format acceptable)
- [ ] Supporting information in separate files
- [ ] ORCID ID for all authors (free at [https://orcid.org](https://orcid.org))

**Title Page Must Include:**
- [ ] Brief informative title with major keywords (no abbreviations)
- [ ] Short running title (<40 characters)
- [ ] Full names of all authors
- [ ] Institutional affiliations where work was conducted
- [ ] Footnote for present address if different from work location
- [ ] Corresponding author(s) with email address(es)

**Ethics and Integrity Statements (in manuscript):**
- [ ] Data availability statement
- [ ] Funding statement
- [ ] Conflict of interest disclosure
- [ ] Ethics approval statement (IRB/ethics committee)
- [ ] Patient consent statement (if applicable)
- [ ] Permission to reproduce material from other sources
- [ ] Clinical trial registration (if applicable)

**Quality Check:**
- [ ] Manuscript is legible and well-organized
- [ ] English language quality is sufficient for editors and reviewers
- [ ] Figures and tables are highest resolution possible (vector format recommended for figures)
- [ ] References are consistent throughout

## Ethical and Technical Requirements

### Abstract

- **Format**: **Structured** (for Research Articles)
- **Length**: No specific word limit stated, but should be concise
- **Content**: Summarize key findings and significance

### Keywords

- **Number**: Maximum 7
- **Content**: Should reflect main topics and findings
- **RRIDs**: Include Research Resource Identifiers if applicable

### Practitioner Points (Optional)

- **Number**: Maximum 3
- **Purpose**: Key points written for practitioners
- **Content**: Summarize key messages for practical application

### Main Text

**Required Order:**
1. Introduction
2. Results
3. Discussion (or combined Results and Discussion)
4. Conclusion
5. Methods
6. Acknowledgement
7. Author Contributions
8. Data and Code Availability
9. Competing Interests
10. References

**Writing Style:**
- Clear, concise, and well-organized
- English language must be of sufficient quality
- Use appropriate scientific terminology

### Figures

**File Requirements:**
- Submit as **separate files** (required at revision stage)
- **Recommended format**: Vector format
- **Resolution**: Highest possible
- **Legends**: Must be supplied as complete list in text

**Figure Guidelines:**
- Number figures sequentially
- Each figure must have a descriptive legend
- Legends should be self-contained (understandable without reference to text)
- [Wiley's Basic Figure Requirements](https://authorservices.wiley.com/asset/photos/electronic_artwork_guidelines.pdf)

**For Post-Acceptance:**
- More detailed figure requirements apply
- [Wiley's FAQs on Supporting Information](https://authorservices.wiley.com/author-resources/Journal-Authors/Prepare/manuscript-preparation-guidelines.html/supporting-information.html)

### Tables

**Requirements:**
- Each table complete with **title and footnotes**
- Can be included in manuscript or as separate files
- Must be numbered sequentially
- Should be self-contained
- Format: Editable format preferred

### References

**Free Format Submission:**
- Any consistent style/format acceptable at submission
- Will be formatted to journal style during production
- **Style**: Follow New Hart's Rules or similar numbered style
- **EndNote Style**: [iMeta EndNote style download](iMeta/Papers/1Template/iMeta.ens)

**Formatting:**
- List in numerical order
- Journal abbreviations should follow standard indexes
- Include DOI where available
- All cited references must be in reference list
- All references in list must be cited in text

### Supplementary Material

**Requirements:**
- Submit as **separate files**
- All supplementary tables recommended in one Excel file
- Must be cited in main text
- Will be published online only
- Not copyedited or typeset
- Must be functional on any internet browser

**File Size:** Combined manuscript files (including text, tables, figures, video, audio) must not exceed **350 MB**
